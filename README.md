## How Viator activity prices are calculated

Two travelers can see different totals for what appears to be the same tour. Common reasons include:

- Different dates
- Different start times
- Different tour options
- Different group sizes
- Adult, child, youth, senior, or infant pricing
- Private versus shared transportation
- Hotel pickup versus meeting point
- Optional add-ons
- Different currencies
- Taxes or service charges
- Availability changes

Viator’s official partner documentation describes both per-person pricing and unit pricing. Per-person products calculate the total using traveler categories, while unit-priced products may charge for a group, vehicle, boat, room, or package.

For that reason, do not compare only the “from” price. Select the date and traveler count first. Then compare the complete total for the exact version of the experience you intend to book.

A low headline price can also represent a basic entry ticket, while a higher option may include transport, skip-the-line access, a guide, meals, equipment, or hotel pickup. The cheapest option is not necessarily the cheapest way to achieve the same itinerary.

## Why a Viator promo code may not work

A rejected code is not always a technical problem. Common causes include:

### The code has expired

Viator says promotional codes normally have expiration dates. A code shared in an old article may have been valid only for a short campaign.

### The activity is excluded

Some experiences may not accept promotional codes, especially products already discounted, tickets with limited inventory, gift cards, or supplier-specific offers.

### The offer is app-only

A code may work only inside the Viator app. Trying it on the desktop website can produce an error even when the promotion itself is genuine.

### The account is not eligible

New-user promotions may not work for an existing account. Other offers may be limited by country, currency, or customer segment.

### The code cannot be combined

A product discount, cashback campaign, referral offer, or coupon may not stack with another promotion.

### The booking route affects eligibility

ShopBack’s Viator terms state that promo codes not featured on its platform may exclude a purchase from cashback. In other words, getting a coupon discount and getting cashback are separate questions. A code can reduce the booking price while making the transaction ineligible for cashback.
